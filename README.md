
# Retail Sales ETL Pipeline
## project overview

This project is about working with retail sales data using Python and MySQL.
 I built an ETL pipeline that takes sales data from a CSV file, checks the data for missing values and duplicates, and prepares it for storage in a MySQL database.

I also used Python to calculate the total amount for each order and SQL queries to analyse the sales data. This helped me understand how ETL pipelines work and how data can be used to get useful information about a business.


## Technologies I Used

1. **Python:** Used to build and run the ETL pipeline.
2. **Pandas:** Used to read, check, and transform the sales data.
3. **MySQL:** Used to store the cleaned sales data.
4. **SQLAlchemy:** Used to connect Python to the MySQL database.
5. **PyMySQL:** Used as the MySQL database driver.
6. **VS Code:** Used to write and manage the project code.
7. **phpMyAdmin:** Used to manage the database and run SQL queries.


## ETL Process

### 1. Extract
I used Pandas to read the retail sales data from a CSV file.

### 2. Transform
I checked the data for missing values and duplicate records, converted the order dates into the correct format, and calculated the total amount for each order using quantity and unit price.

### 3. Load
I used SQLAlchemy to connect Python to MySQL and loaded the cleaned sales data into the database.


## SQL analysis

After loading the data into MySQL, I used SQL queries to analyse the sales information. The queries helped me:

1. Calculate the total sales revenue.
2. Identify the revenue generated by each product.
3. Compare revenue between product categories.
4. Calculate daily sales revenue.
5. Identify the highest and lowest spending customers.


## Project results

1. Successfully processed 10 retail sales records.
2. Calculated a total sales revenue of R57,500.
3. Identified Electronics as the highest revenue-generating category.
4. Identified Laptop as the product generating the most revenue.
5. Identified Thabo as the highest-spending customer.
6. Successfully loaded the cleaned sales data into MySQL.


## What I learned

Through this project, I gained practical experience working with Python, Pandas, SQL, and MySQL. I learned how to build a basic ETL pipeline, perform data quality checks, transform data, connect Python to a database, and use SQL queries to analyse sales information.
